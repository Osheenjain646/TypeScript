# TypeScript Basic Types

## Terminologies

- **Strongly Typed languages**:- Demand the specification of data types.
- TS is a Strongly types language.

- **Loosely Typed Languages**:- Do not require type specification.
- JS is a Loosely typed language or also known as weakly typed.

- These two relates to the Static Typing and Dynamic Typing but it is not the same.

- A language that is strongly typed and either be statically or dynamically typed language.

- TS is a statically typed language. This means that types are checked at the compile time.

- JS is a dynamically typed language. This means that typed are checked dynamically at run time.

## Some Benefits of TS includes:-

- Self-Documenting
- Catch errors in development instead of at running application
- good for teams
